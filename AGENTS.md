# Repository instructions

## QA and test files

- The owner does not want QA or automated test files in this repository.
- Do not create or retain test suites, test fixtures, QA reports, screenshots,
  or test-only scripts and dependencies unless the owner explicitly requests them.
- If you create temporary files for verification, remove those files before
  completing the task. Remove any test commands or test-only dependencies you
  added for those files as well.
- Prefer non-persistent checks, such as syntax checks and reviewing diffs, when
  verification is useful. Do not leave QA artifacts in the project.
